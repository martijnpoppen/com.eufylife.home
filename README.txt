DEPRECATED — please move to "Anker Eufy"

This app is no longer being developed. It is replaced by Anker Eufy, which supports your robot
vacuums alongside the rest of the eufy range — cameras, video doorbells, HomeBases, locks, keypads,
sensors, mowers and lights — all in one app.

  https://homey.app/a/com.eufy/

How to move across:
- Install Anker Eufy from the Homey App Store.
- Add your devices there. A Homey device belongs to the app that created it, so the devices have to
  be paired again and the Flows that used them rebuilt.
- Remove this app once you are happy. Both apps can run side by side until then, so you can move one
  device at a time.

This app still works and will keep working while you move. It will not receive new devices or new
features.


Adds support for Eufy Clean

Retrieve information from your Eufy Robovac.
Get notification when a value has changed.

Current features:
- Switch on / off. When off, it will returning to charging dock automatically.
- Display battery level, and notify on low battery.
- Display battery charging state.
- Find robot
- Start Scenes (Robovac X10)


How to use:
- Install this app on your Homey.
- Add a device.
- Login with your Eufy Account
- Use the app

Is my device supported?
- Go to https://tinyurl.com/eufy-clean-homey and check if your device is listed.
